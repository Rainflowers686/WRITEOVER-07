# WRITEOVER-07 · 重写协议：执行官07

[English](README.en.md) · [语言入口](README.md)

一款在终端里运行的单人第一人称探索与战斗游戏。你从设施 B1 醒来，沿着权限、
口供和记录向上调查。门可以按规程打开，也能设法绕过。枪声、摄像头和倒下的人
不会在你离开房间时就被忘掉。

远看是低分辨率的第一人称空间，走近能看见组成门框、护甲和武器的字符。
它不是把普通图片转换成像素块：人物和枪械使用手工设计的字符轮廓。

## 先玩起来

当前源码候选版为 `0.2.0-candidate.1`。发布页中已附上的平台包才是可下载版本。

1. 在 Assets 下载游戏包，不要选 Source code。Windows 包以 `win-x64.zip` 结尾。
2. 完整解压，保留 `data` 文件夹，运行 `WRITEOVER-07.exe`。
3. 首次选择简体中文或英文，再选“新游戏”；已有恢复存档时可选“继续”。

使用支持 Unicode／中文的等宽字体。最低 48×18 个字符单元，80×30 或更大
更容易阅读。窗口太小时游戏会暂停。候选包未签名，请核对来源和校验值，
不要关闭系统防护。

## 你可以怎么玩

先检视设备、读记录、问工作人员，再决定怎么通过下一道门。电击器提供非致命
选择，但要消耗弹药，也可能留下被发现的现场。安静通行与强行闯入都有后果。

案件档案显示当前目标、已知线索、取得的关键记录和通行情况。错过一句话，可以
在暂停菜单翻对话或最近事件。它们帮助你整理已经知道的事，不会直接泄露结局答案。

现有流程从 B1 通往屋顶，共 19 个可玩房间，包含支路、回访和三种结局。
目录中提到的 41 层是世界设定，**不是 41 个可以进入的关卡**。

## 常用操作

| 操作 | Windows 默认键 |
|---|---|
| 移动／观察 | WASD／鼠标 |
| 交互／检视 | F／鼠标右键 |
| 开火／装填 | 鼠标左键／R |
| 武器选择 | 1 手枪、2 SMG、3 电击器 |
| 案件档案 | F1 |
| 保存／读取最近恢复存档 | F5／F9 |
| 暂停／返回 | Esc |

右键不是瞄准镜模式。完整键位见游戏内“操作说明”。
设置中可改键，冲突会提示，保存前需确认；方向键、F 和 Esc 保留安全菜单操作。

## 阅读、恢复与舒适度

中英文可在设置中切换。视野、鼠标、字幕时长、感知信息、对比度、减弱晃动／
闪烁、音量和帧率上限也可调整。难度调整玩家承受的伤害，不改变证据和路线。
Auto 最高跟随 120 Hz 模拟节拍，不代表实测显示帧率。

手动存档、检查点和最终选择前存档分开。暂停菜单可以回到检查点或最终决策前；
新游戏先确认，不会立刻删除所有旧槽位。更新前请备份重要存档。
[指南](docs/release/PLAYER_GUIDE.zh-CN.md) 解释了保存位置和失败时的行为。

## 试玩边界与反馈

内容包含枪械、致命与非致命战斗、昏迷者、死者、藏匿身体和机构悬疑。
