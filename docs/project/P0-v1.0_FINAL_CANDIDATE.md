# P0-v1.0 FINAL CANDIDATE（第四轮 Opus 规划红队的唯一产品基线）

> 状态：产品/技术范围候选冻结。
> 第四轮 Opus **不重新设计产品**，只允许发现真正 Fatal 时做必要缩减或调整制作顺序。
> 当前时间：2026-09-02 16:34 CST。

## 1. 产品身份

暂名：
`WRITEOVER-07 / 重写协议：执行官07`

一句话：
> 一款真实运行在 Windows 终端中的全屏第一人称高刷新彩色字符 3D 沉浸模拟 FPS：玩家通过爽快射击、立体潜入、系统解谜与人物互动，对抗一个会撒谎、会控制世界界面、能够被反制的旁白系统；玩家每一个有意义的行为都留下可以被看见的因果后果。

题材：
- 架空巨型企业 / AI 组织
- “记忆矫正与叙事测试中心”
- 不映射现实政治、学校、现实人物

主角：
- 安保执行员 07
- 过去被抹除
- 行为塑造人格
- 真实身份是谜底之一

## 2. 三大支柱

任何新功能若不能显著强化下列至少一项，禁止加入：

1. **高刷新字符 3D 中的爽快射击与立体潜入**
2. **有权限、有资源、会撒谎且可被反制的旁白**
3. **每个有意义行为都留下可观察因果后果**

## 3. 主体验

前三分钟必须完成：
1. 真实第一人称字符 3D
2. 玩家移动、鼠标观察
3. 拿枪并完成第一枪
4. 遇到工程师
5. 旁白第一次“字面真实但整体误导”
6. 玩家作出至少 2 种有效处理
7. 30–60 秒内产生可见回调
8. 出现一个立体动作 beat（蹲/探头/趴/跳中的至少两个）

完整体验：
- 正常首次通关 25–30 分钟
- Judge Mode 8–10 分钟
- 5 分钟课堂展示只展示 3 个“哇”点

## 4. 引擎

P0：
**Height-Aware Grid / Height-Span Raycaster**

禁止：
- Sector/Portal
- BSP
- 任意三角网格
- 重叠多楼层
- 斜坡
- 大规模可破坏几何

Grid:
- 1.0m × 1.0m
- 每格 floorHeight / ceilingHeight / material / light
- 动态门/低门/通道/平台/沟槽由高度与实体表达

一条视线允许多个 vertical span，不采用“首墙命中即结束”的传统等高 raycaster。

## 5. 性能

所有正常预设：
- Simulation = 固定 120Hz

参考机：
- Win11
- Windows Terminal
- ≥120Hz 显示器

目标：
- ULTRA120：240×67 字符，Internal Render 1% Low ≥120 FPS
- HIGH_REFRESH：192×54，Internal Render 1% Low ≥120
- PRESENTATION_60：200×60，Render ≥90，Present 60
- COMPATIBILITY：160×45，Render ≥60，Present ≥60

不承诺未知 60Hz 投影物理显示 120 个不同画面。
必须：
- 无滚屏
- 无明显闪烁
- 无 Present backlog
- 退出恢复终端

并发策略：
- R0 先单线程 Sim + Render
- profiler 证明需要才引入 Present thread / render workers
- 世界逻辑永远单线程

## 6. 字符渲染

- 主后端 ANSI VT TrueColor
- 256 色中档
- Win32 WriteConsoleOutputW 兼容回退
- 主 3D 栅格只使用可靠单宽字符/半块字符
- 中文仅 HUD / 字幕 / 菜单独立层
- 启动校准字符宽高比
- 能力探测 + 自动预设
- 不允许 `system("cls")`
- 不允许逐字符 cout
- 不允许逐行 flush

## 7. 玩家动作

P0 必须支持：
- 行走
- 冲刺
- 跳跃
- 蹲伏
- 趴下
- 左右探头
- 翻越
- 攀上
- 固定梯
- 高处坠落
- 有限俯仰 ±30°

初始尺度：
- Stand collider 1.80m / eye 1.60m
- Crouch collider 1.20m / eye 1.00m
- Prone collider 0.55m / eye 0.42m
- Lean ±0.35m

净空：
- prone-only 0.65–0.85m
- crouch-only 1.30–1.55m
- standing ≥1.90m

跳跃：
- 由速度/重力真实积分
- 不在代码里写“2格可跳”规则

R0 若姿态系统失败：
- Prone + Vault 延期 P1
- Stand/Crouch/Jump/Lean 必须保留

## 8. 战斗

P0 武器/工具：
1. 手枪
2. 冲锋枪/短步枪
3. 非致命电击器 / 系统工具

目标：
- 第一枪 30 秒内出现
- 明显枪口反馈
- 后坐
- 换弹
- 命中
- 爆头或高价值命中
- 受击反馈
- 声音传播影响 AI

P0 命中：
- Camera / view-center hitscan
- Near-wall weapon lower
- 极近墙禁 ADS / 限制射击
- 不做完整 muzzle ray

- Stretch Rooms = 0

- 社会关系

## 10. NPC

P0：
- 2 Full NPC
- 2 Medium NPC
- 3 Light NPC
- 普通守卫 / agents 6–10
- 同屏上限 8

Full NPC：
- 感知
- 长期记忆
- 关系
- Fact/Belief
- Utility
- GOAP-lite
- Storylet

GOAP-lite：
- 仅 2 Full
- 目标候选 ≤3
- 动作集 ≤10
- 规划深度 ≤5
- 重规划 ≤5Hz / 事件触发

Medium：
- 感知 + FSM + 有限记忆
- 无 GOAP

Light：
- FSM / 警戒 / 战斗 / 逃跑

屏幕外：
- 1–2Hz 轻量模拟
- 不允许主线关键物永久丢失
- 不允许无预警导致不可恢复剧情

NPC/Storylet/房间必须数据驱动，不允许 4 个 NPC 写成 4 套专用代码。

- 世界状态

- 资源
- 旁白态度/权限
- Storylet
- 结局条件
之一。

- Fact ≤120
