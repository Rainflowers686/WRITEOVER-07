# 五分钟课堂演示

这是一份演示预算，不是实测通关时间。不要试图五分钟现场从 B1 跑完整战役。
提前在独立演示用户目录中，用正常玩法准备“上层电梯可用”和“最终选择前”存档。
不要修改事实文件伪造进度，不要覆盖个人存档。用包内实际键位完成一次彩排。

| 时间预算 | 屏幕操作 | 讲解重点 | 现场失败的退路 |
|---|---|---|---|
| 0:00–0:40 | 启动，选择中文或英文，进入 B1 | 单机字符第一人称，人物、武器、门框由 glyph 组成 | 使用已核实的生产导出图，明确不是现场画面 |
| 0:40–1:20 | 对准医护或设备，检视并交互 | 距离、朝向、LOS 决定可见目标，提示显示当前绑定 | 换近处已知可交互对象，不在现场调试代码 |
| 1:20–2:10 | 演示一条已彩排的摄像头或非致命后果；查看感知消息 | 玩家行动改变事实，字幕只是表现，不是后果本身 | 展示实际回放日志和画面，明确为自动回放 |
| 2:10–2:50 | F1 案件档案，滚动关键记录；设置切换语言 | 只列已获得知识，切语言不重触发剧情 | 展示档案截图，说明取得记录的正常路径 |
| 2:50–3:40 | 读取准备好的上层进度，打开电梯目录 | 19 个可玩房间，41 层是设定；解锁由事实决定 | 展示目录导出图，不声称所有楼层可进入 |
| 3:40–4:30 | 使用最终选择前槽位，展示可用选项并确认一个结局 | 资格由已有事实读取，结局与恢复槽位分离 | 用已保存的结局摘要，不临时手改条件 |
| 4:30–5:00 | 回到架构或存档图 | 固定步长、模块接口、先验证再提交，真人验收独立 | 口头收束，不超时跑测试 |

演示前检查：终端字体和尺寸、中英文都能读、音量合适、控制绑定明确、存档来源
可解释、私人路径不显示在投影上。若声音设备不工作，用文字提示说明当前状态，
不要关闭系统防护或临时安装驱动。最后保留组间测试的代码与功能评分，由同学填。

建议开场话术：“这是一个用字符构成世界的单机游戏。我们演示一次交互怎样留下
后果，以及存档怎样恢复这些后果。完整流程有十九个房间，今天用准备好的进度
展示上层和结局，不把快速演示当成通关。”
