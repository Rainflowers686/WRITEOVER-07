## 执行方式

配置并构建 Release 后，`scripts/run_qa.ps1 -Tier FAST_REQUIRED` 运行提交门禁。
`-Tier EXTENDED` 保留恢复、场景矩阵、Act II 和完整结局/重载验证。
每次使用新的证据目录，保留 stdout、退出码和 `qa-result.json`，不覆盖失败现场。
详见 [测试策略](../engineering/TEST_STRATEGY.md)。
