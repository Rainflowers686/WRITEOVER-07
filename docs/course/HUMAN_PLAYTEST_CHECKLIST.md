# 真人验收清单

开始前记录：测试者、日期、版本、包 SHA-256、系统、终端、字体、窗口尺寸。
每项填写 PASS / FAIL / NOT_RUN，并记录实际现象。空白不等于通过。

- [ ] 独立新用户目录的中文首次启动、语言选择、开场与关键提示可读。
- [ ] 独立新用户目录的英文首次启动；中途切换语言后档案、历史和菜单正确刷新。
- [ ] 窗口缩小、低于 48×18、重新放大；暂停原因、鼠标目标和宽字符位置正确。
- [ ] 80×30 和日常窗口中的字幕、页脚、档案滚动不被截断。
- [ ] NPC 面部、四向、人物比例、手持武器与建筑门多角度观感可接受。
- [ ] 改键成功、冲突被拒、取消不生效、恢复默认不清空其他设置；关菜单不误开火。
- [ ] 字幕时长、感知详略、对比度、减弱晃动／闪烁、FOV、鼠标反转有效。
- [ ] 真机试听总音量与分项音量、音效强弱和舒适度；无音频设备时状态解释清楚。
- [ ] 第一次游玩的同学不看攻略完成首个目标，并能说出下一步去哪里。
- [ ] 检视、交互、非致命后果、摄像头／警戒信息不造成玩家误解。
- [ ] 手动保存、继续、检查点、最终选择前恢复和新游戏的行为符合指南。
- [ ] 结局选择与摘要可理解，确认不会被误触，已有记录不会凭空增加。
- [ ] 分别实际游玩一条安静路线和一条交战路线，检查感知信息与后果是否一致。
- [ ] 到达屋顶，确认最终画面和离场反馈；退出程序、重新启动并恢复结局存档。
- [ ] 实际计时：开始、暂停、结束、路线和是否使用攻略分别记录，不套用回放帧数。

课程交换测试另填：代码质量 ____ / 50，功能体验 ____ / 50，评分理由和复现问题。
自动化 CI、SVG/PNG 导出、源码阅读和模型评价都不能代填这些真人结果。
