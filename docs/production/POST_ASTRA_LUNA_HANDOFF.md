- Slate architecture, bone edges, ochre maintenance, muted sea-green equipment,

- HUD action/objective text is literal and compact. Narrator is an exact,

## PRESENTER_CRITICAL_KNOWLEDGE

| System | Rain's essential explanation |
|---|---|
| Architecture / game loop | `src/app/composition_root.cpp` wires modules. Fixed 120Hz simulation and presentation cadence are different responsibilities; no render-driven gameplay clock. |
| Raycasting / renderer | `CastColumnRay` walks XY cell boundaries and records vertical opening changes; `CameraProjection` maps them to terminal cells. Finite floor/ceiling spans and wall faces share occlusion with actors. |
| Character-Art | `CharacterArtBank` loads authored glyphs, opacity, facing and LOD. Spaces are air; `~` is authoring-only occupied blank. Shapes are not rasterized pictures. |
| Interaction | Camera ray, bounded target and line of sight select a candidate; capabilities/facts then authorize the action. A visible door is not necessarily unlocked. |
| AI | `AutonomousNpcSystem` separates perception, memory, intent and motor. A cleaner must actually arrive to discover a body. |
| Systemic facts | Event, observer knowledge and durable consequence are distinct. Concealing a body does not erase the event or historical memory. |
| Narrative / storylets | `NarrativeModule` lives in composition, not the module shim. Existing conditions select scene-eligible actions; presentation waits without consuming blocked once-only lines. |
| Save/load | `SaveManager` sections are staged/validated before authoritative commit; injected failures must restore the previous state byte-for-byte. |
| Content pipeline | JSON/text authoring compiles deterministically to .woc/.bin. `contentc --check` checks actual bytes against source. |
| Testing | Unit predicates, replay outcome oracles, negative probes, production frames and human acceptance answer different questions. |
| Cross-platform | Platform-neutral C++17 core; terminal/input/audio backends differ. Runtime CI and link-only evidence must be labeled separately. |
