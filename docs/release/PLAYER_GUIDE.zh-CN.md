# WRITEOVER-07 玩家指南

适用于 `0.1.0-complete-campaign-candidate` Windows x64 试玩包。

## 安装和启动

从 [本版下载页](https://github.com/Rainflowers686/WRITEOVER-07/releases/tag/candidate-0.1.0-complete-campaign-20260915) 下载 `WRITEOVER-07-audit-candidate.zip`，完整解压后运行 `WRITEOVER-07.exe`。程序旁的 `data` 是游戏内容，不能只复制 exe。

也可以在解压目录打开 PowerShell，运行：

```powershell
.\WRITEOVER-07.exe
```

这样如果程序退出，你仍能看到报错文字。请使用 Unicode 等宽字体；菜单至少需要 48×18 个字符单元。字符挤在一起或界面被截断时，先扩大窗口或调小字体。

首次进入选 New Game。Continue 只有在存在可用的恢复存档时才可选。菜单用 W/S 移动选择、F 确认、Esc 返回；A/D 用于滚动长文本。

## 在 B1 该做什么

先看目标提示，靠近设备或工作人员，用 F 交互。鼠标右键可以检视眼前的目标。提示距离不够时，走近一点再试。

F1 打开案件档案。它列出你已经知道的目标、线索、证据和通行情况，不是一份提前揭示所有答案的攻略。刚才的对话没看清，可以暂停后打开 Dialogue 或 Recent Events。

安静通行、利用设备和武力处理会产生不同后果。摄像头状态、声音、人员倒下的位置以及被谁发现，都可能影响后面的遭遇。电击器不是无限弹药，也不能保证现场不会被发现。

## 保存、死亡和重新开始

F5 手动保存。Continue 和 F9 读取最近一次成功写入的恢复存档；暂停菜单还有 Restart Checkpoint 和 Replay Final Choice，分别使用章节检查点和最终选择前的存档。

这些槽位不是同一个文件。完成结局后，Ending Summary 可以回看结果；Replay Final Choice 让你回到当时的选择前，不会凭空补上尚未发现的证据。

New Game 会先询问，再重建当前游戏进度。偏好设置会保留，旧磁盘存档不会被立即全部删除，但以后保存会替换对应槽位。

死亡状态不能保存。如果没有恢复存档，F9 的入口恢复会保留世界里已经发生的后果，并非重开整个世界。损坏存档会被拒绝，不会悄悄换成另一局。

Windows 默认位置：

- 存档：`%LOCALAPPDATA%\WRITEOVER-07\saves\`
- 设置：`%LOCALAPPDATA%\WRITEOVER-07\settings.cfg`

更新前请自己备份需要保留的存档。不要把“本版存档回归通过”理解为所有旧版本、所有修改过的文件都兼容。

## 让画面和文字适合你

Settings 提供字幕、文字显示时长、感知消息详略、高对比度、减弱晃动／闪烁、音量和鼠标灵敏度。关闭即时感知消息后，仍可以查看历史。

Frame Limit 可以选 Auto、30、60、120。Auto 最高跟随 120 Hz 模拟节拍；这不是实际显示帧率保证。特效按游戏时间计时，降低呈现帧率不会把闪光拖长。

## 范围和限制

这版从 B1 通往屋顶，共 19 个可玩房间、三种结局。目录中的 41 层不是 41 张可进入的地图。当前发布附件只有 Windows x64 版本；不要把旧 PVS-01 的 Linux/macOS 包当成同一内容版本。

程序未做代码签名。遇到系统警告时核对来源和 SHA-256，不要为了试玩关闭系统防护。当前还未完成独立真人音频、视觉和首次试玩验收。
