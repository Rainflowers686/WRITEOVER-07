# WRITEOVER-07 玩家指南

适用于 `0.2.0-candidate.1`。这是试玩候选版，不是正式 1.0。

## 下载和启动

从 [Releases](https://github.com/Rainflowers686/WRITEOVER-07/releases) 选择本版，
在 Assets 中下载适合系统的游戏包；Source code 不是可直接玩的程序。
Windows 包名为 `WRITEOVER-07-v0.2.0-candidate.1-win-x64.zip`。
完整解压后运行 `WRITEOVER-07.exe`，不要单独移动程序或删除旁边的 `data`。

如果启动后立即退出，在解压目录的 PowerShell 中运行：

```powershell
.\WRITEOVER-07.exe
```

这样能保留报错文字。使用支持中文和 Unicode 的等宽终端字体。界面至少需要
48×18 个字符单元，80×30 或更大的窗口更便于阅读。窗口过小时会暂停；
扩大后恢复。不要把字体显示异常误当作已通过验收的美术效果。

首次启动先选简体中文或 English，然后选“新游戏”。有恢复存档时可选“继续”。
暂停后的设置中也可以换语言，不必重开存档。

## 从 B1 开始

看当前目标，靠近设备或工作人员。准星对准可交互目标后，按屏幕提示操作。
默认 F 交互，鼠标右键检视；右键不是瞄准镜模式。没有提示时，试着靠近、
换个角度，或看看是不是被墙挡住了。

F1 打开案件档案。这里有当前目标、已知线索、通行情况和实际取得的关键记录，
不会提前显示所有结局条件。错过一句话，可以暂停查看“对话”或“最近事件”。
开场提示只在需要时短暂出现，不会替你走完流程。

调查记录、与人交谈、操作设备和使用武力，后果并不相同。摄像头、枪声和
被发现的身体可能影响后面的遭遇。电击器有实际弹药；非致命不等于不会被发现。
明确来源的受击会提示大致方位，不会给出敌人坐标或隔墙透视。

| 动作 | Windows 默认键 |
|---|---|
| 移动／观察 | WASD／鼠标 |
| 交互／检视 | F／鼠标右键 |
| 开火／装填 | 鼠标左键／R |
| 手枪／SMG／电击器 | 1／2／3 |
| 电击器快捷操作 | V，消耗弹药 |
| 冲刺／跳跃 | Shift／Space |
| 蹲下／趴下 | Ctrl／Z |
| 左右探身 | Q／E |
| 案件档案 | F1 |
| 手动保存／读取恢复存档 | F5／F9 |
| 暂停、返回 | Esc |

普通菜单可用移动键选择和滚动，也保留方向键、F 确认、Esc 返回的安全操作。
以当前页脚提示为准。设置中的“重新绑定按键”会先让你选动作，再按新键；
冲突会被拒绝，最后还需确认。捕获或确认阶段可按 Esc 取消。
方向键保留给菜单导航。“恢复默认绑定”只重置按键，不清空其他偏好。
Controls／操作说明和游戏提示会显示修改后的键位。

## 保存、死亡与重开

手动保存、章节检查点、最终选择前、结局完成后和最近恢复存档各有用途。
“继续”和 F9 读取最近成功写入的恢复文件；暂停菜单可以重启检查点，或回到
最终选择前。回放最终选择不会凭空补给你从未找到的证据。

一次保存的主槽位和最近恢复文件分别写入。若只写成其中一个，游戏会报告
部分失败，不应把它当作所有槽位都更新成功。损坏文件会被拒绝，不会悄悄换
成另一局；读取失败时已运行的状态应保留。升级前仍请自行备份重要存档。

“新游戏”需要确认，会重建当前进度并保留偏好。原磁盘存档不会立刻全部删除，
但以后保存会替换对应槽位。死亡不能保存；若没有恢复文件，F9 的入口恢复
会保留世界中已经发生的后果，不等于重开整个世界。

Windows 用户数据位于 `%LOCALAPPDATA%\WRITEOVER-07\`，存档在其中的
`saves`，设置在 `settings.cfg`。Linux 使用
`$XDG_DATA_HOME/WRITEOVER-07`，未设置时为
`~/.local/share/WRITEOVER-07`；macOS 使用
`~/Library/Application Support/WRITEOVER-07`。这些目录独立于安装目录。

## 画面、声音和阅读

设置提供语言、字幕、文字时长、感知信息详略、高对比度、减弱晃动与闪烁、
鼠标灵敏度、视野、纵轴反转、交互提示强调、总音量和分项音量。
当前音效是程序化声音，不是完整配音。声音依赖平台和设备，不能把音量滑项
存在理解为 Linux/macOS 拥有和 Windows 相同的音频实现。

战斗难度调整玩家承受伤害：简单约为普通的 75%，困难约为 125%，并有整数取整。
它不改变门禁条件、证据或结局。帧率上限可选 Auto、30、60、120；
Auto 最高跟随现有 120 Hz 模拟节拍，实际显示帧率取决于电脑与终端。

## 范围和注意事项

本版有 19 个可玩房间，从 B1 通往屋顶，包含回访、支路和三种结局。
设施目录中的 41 层是设定，不是 41 个可进入关卡。发布页有什么平台附件，
就以实际附件为准；旧 PVS 包不是本版战役。

内容包含枪械、致命与非致命战斗、昏迷者与死者、藏匿身体和机构悬疑。
候选包没有代码签名；核对下载来源与 SHA-256，不要关闭系统防护。
真实终端、音频试听和首次玩家体验仍需人工验收。没有固定通关时长保证。
