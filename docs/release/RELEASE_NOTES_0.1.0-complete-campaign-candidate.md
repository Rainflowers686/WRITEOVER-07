# WRITEOVER-07 完整战役试玩候选版

版本：`0.1.0-complete-campaign-candidate` · 发布日期：2026-09-15 · Windows x64 · Pre-release

你可以从 B1 开始，经过下层工作区和上层设施，走到屋顶的结局。这版有 19 个可玩房间、回访路线和三种结局。设施目录中的 41 个楼层是设定，不代表 41 个可玩关卡。

## 从旧 PVS-01 更新后能看到什么

旧版只覆盖下层试玩路线。这次提供既有完整战役，以及开始／暂停菜单、继续游戏、新游戏确认、案件档案、检视、事件和对话回看。

存档区分手动保存、章节检查点、最终选择前和结局完成状态。新游戏会重建当前进度；读档后会清掉来自后续事件的字幕、历史和短暂视觉效果。设置增加了更容易找到的文字、感知提示和帧率选项。

门框现在有连贯的门楣与门柱，墙面纹理更安静，屋顶有室外平台与远处建筑群。人物、枪械仍使用手工字符资产，游戏没有切换到像素画面。

终端输出减少了临时字符串和多余颜色指令，并修正跨行、局部刷新时的颜色状态。帧率限制不再重复计入绘制耗时；低帧率下的短暂效果按游戏时间结束。CPU 基准有改善，但没有测得可以承诺给所有电脑的实际显示 FPS。

## 下载和启动

下载 Assets 中的 `WRITEOVER-07-audit-candidate.zip`，完整解压后运行 `WRITEOVER-07.exe`，保留同目录的 `data`。新玩家选择 New Game。

中文说明在附件 `PLAYER_GUIDE.zh-CN.md`；ZIP 中也包含英文 README。WASD 移动、鼠标观察、F 交互、右键检视、左键开火、R 装填，Esc 暂停。更多键位以游戏内 Controls 为准。

本次只提供 Windows x64 包。GitHub 自动生成的 Source code 是源码，不是可直接运行的游戏。

## 存档和已知限制

升级前请备份 `%LOCALAPPDATA%\WRITEOVER-07\` 中需要保留的存档。设置和存档与安装目录分开；跨版本兼容性没有无限保证。

这还是试玩候选版。前台终端观感、音频试听、首次玩家体验和最终机械审计尚有待完成。包未做代码签名；不要为了运行它关闭系统防护。源码中的 Linux/macOS 支持不代表本次已经提供对应的新下载包。
